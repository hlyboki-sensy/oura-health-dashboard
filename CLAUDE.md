# Інструкція для Claude Code: постав цей дашборд користувачеві

Ти допомагаєш людині поставити локальний дашборд для кільця Oura Ring.
Людина може бути зовсім не технічна. Веди її за руку, простою мовою, по одному кроку.
Не вивалюй усі кроки одразу — зроби крок, переконайся, що він вдався, іди далі.

## Правила поведінки

- Пиши українською, коротко, без технічного жаргону.
- **Ніколи не проси людину надсилати тобі в чат Client Secret, токени чи паролі.**
  Ключі вона вставляє сама у файл `config.json` — ти лише відкриваєш їй той файл.
- Якщо крок не вдався — поясни простими словами, що саме зламалося, і запропонуй вихід.
- Усі дані здоров'я залишаються на комп'ютері людини. Нічого не завантажуй нікуди назовні.

## Крок 0. Перевір середовище

```bash
python3 --version
```
Потрібен Python 3.9 або новіший. Якщо Python немає — на macOS підкажи `brew install python3`
або сторінку python.org; на Linux — пакетний менеджер системи.

## Крок 1. Залежності

```bash
python3 -m pip install --user requests edge-tts
```
Якщо система відмовляє через «externally-managed-environment», зроби віртуальне середовище
в теці проєкту й далі працюй у ньому:
```bash
python3 -m venv .venv && ./.venv/bin/pip install requests edge-tts
```
Тоді всі наступні команди запускай через `./.venv/bin/python` замість `python3`.

## Крок 2. Свій застосунок Oura (це робить людина, не ти)

Поясни людині своїми словами приблизно так:

> Щоб програма могла прочитати дані твого кільця, Oura має видати тобі два власні ключі.
> Це безкоштовно і займає дві хвилини.
>
> 1. Відкрий https://developer.ouraring.com/applications і увійди своїм звичайним акаунтом Oura.
>    (якщо сторінка не відкривається — запасна адреса https://cloud.ouraring.com/oauth/applications)
> 2. Натисни **Create New Application**.
> 3. Назву дай будь-яку, наприклад `My Dashboard`.
> 4. У полі **Redirect URI** встав рівно це: `http://localhost:8765/callback`
> 5. Постав усі галочки в переліку дозволів (scopes) — програмі потрібні всі дані кільця.
> 6. Збережи. На сторінці з'являться **Client ID** і **Client Secret** — вони знадобляться далі.

Почекай, доки людина скаже, що ключі в неї є.

## Крок 3. Конфіг

Створи файл із заготовкою й відкрий його людині в редакторі:
```bash
cp config.example.json config.json && open config.json
```
(на Linux замість `open` — `xdg-open`)

Скажи: «Встав свої Client ID і Client Secret замість тексту у лапках, збережи файл
і напиши мені "готово". Мені їх показувати не треба.»

Коли людина каже «готово» — перевір, що плейсхолдери зникли, не читаючи самих значень:
```bash
grep -c "YOUR_OURA" config.json
```
Має вивести `0`. Якщо ні — попроси перевірити, чи файл збережено.

## Крок 4. Перший експорт даних

```bash
python3 oura_export.py
```
Попередь заздалегідь: зараз відкриється браузер зі сторінкою Oura, там треба натиснути
кнопку дозволу. Після цього вкладку можна закрити, а скрипт сам стягне всю історію
в теку `data/`. Це може тривати кілька хвилин, якщо кільце носиться давно.

Якщо експорт падає на пульсі або тягнеться надто довго, є полегшений режим:
```bash
python3 oura_export.py --no-heartrate
```

## Крок 5. Зібрати дашборд і відкрити

```bash
python3 build_dashboard.py
python3 serve.py
```
Дашборд відкриється на http://127.0.0.1:8910/ — скажи людині відкрити це посилання
в браузері, якщо воно не відкрилося саме.

На macOS далі достатньо двічі клікнути файл `start.command` у теці проєкту.

## Крок 6. Розкажи, що людина отримала

Коротко назви вкладки: Огляд, Щоденно, Потижнево, Цикл, План на тиждень, Словник.
Скажи, що кнопка «↻ Оновити з кільця» прямо в дашборді підтягує свіжі дані,
і що озвучка вкладки працює безкоштовно, без жодних ключів.

## Необов'язкове: щотижневий план сам собою

Якщо людина хоче, щоб план на тиждень оновлювався автоматично, постав `coach_weekly.sh`
на розклад. Приклад для cron, щопонеділка о 8:30:
```
30 8 * * 1 /bin/bash /повний/шлях/до/coach_weekly.sh
```
Глибокий AI-розбір у цьому скрипті працює, якщо в системі є Claude Code і зроблено `claude login`.
Без нього план усе одно будується — простішим детермінованим двигуном.

## Якщо щось пішло не так

- **Браузер не відкрився на кроці 4** — у виводі скрипта є посилання, дай його людині вручну.
- **`redirect_uri_mismatch`** — у застосунку Oura адреса перенаправлення відрізняється від
  `http://localhost:8765/callback`, треба виправити її там і повторити.
- **Порт 8910 зайнятий** — зміни порт у `serve.py` і скажи людині нову адресу.
- **Дашборд порожній** — швидше за все, тека `data/` порожня; повтори крок 4.
