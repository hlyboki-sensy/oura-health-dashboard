# Як поставити собі цей дашборд

Покрокова інструкція для людини без технічного досвіду.
Усе, що тут описано, безкоштовне, а дані з кільця залишаються на твоєму комп'ютері.

Потрібні дві речі: кільце Oura з акаунтом і комп'ютер на macOS або Linux.

---

## Шлях А. Через Claude Code — найпростіший

Claude Code — це помічник, який виконує команди на комп'ютері замість тебе.
Ти йому кажеш словами, що треба, а він робить.

### 1. Постав Claude Code

Завантаж застосунок Claude для комп'ютера з https://claude.ai/download,
увійди у свій акаунт і відкрий у ньому вкладку **Code**.

### 2. Скажи йому одну фразу

Скопіюй цей текст і встав у вікно Claude Code:

```
Постав мені дашборд для кільця Oura Ring.

1. Склонуй репозиторій https://github.com/hlyboki-sensy/oura-health-dashboard
   у мою домашню теку (якщо git недоступний — просто скачай архів і розпакуй).
2. Зайди в теку проєкту, прочитай файл CLAUDE.md і виконай усе, що там написано.

Я не програміст. Пояснюй простими словами, роби по одному кроку
і чекай на мою відповідь після кожного.
```

Далі просто відповідай на його запитання. Один крок він за тебе зробити не зможе —
треба буде взяти два ключі у себе в акаунті Oura, і він скаже, коли й де.

### 3. Готово

Дашборд відкриється у браузері за адресою `http://127.0.0.1:8910/`.
Щоб відкрити його наступного разу, достатньо двічі клікнути файл `start.command`
у теці проєкту.

## Шлях Б. Руками, якщо Claude Code немає

### 1. Скачай проєкт

Відкрий https://github.com/hlyboki-sensy/oura-health-dashboard,
натисни зелену кнопку **Code** → **Download ZIP** і розпакуй архів.

### 2. Відкрий Термінал у теці проєкту

На macOS: правий клік по теці → **Служби** → **Новий термінал у теці**.

### 3. Постав дві бібліотеки

```bash
python3 -m pip install --user requests edge-tts
```

### 4. Візьми два ключі в Oura

1. Відкрий https://developer.ouraring.com/applications і увійди своїм акаунтом Oura.
2. Натисни **Create New Application**.
3. Назву дай будь-яку, наприклад `My Dashboard`.
4. У полі **Redirect URI** встав рівно це: `http://localhost:8765/callback`
5. Постав усі галочки в переліку дозволів.
6. Збережи. З'являться **Client ID** і **Client Secret**.

### 5. Впиши ключі у файл

```bash
cp config.example.json config.json
open config.json
```

Заміни текст у лапках на свої Client ID і Client Secret, збережи файл.

### 6. Стягни дані з кільця

```bash
python3 oura_export.py
```

Відкриється браузер зі сторінкою Oura — натисни кнопку дозволу й закрий вкладку.
Далі скрипт сам забере всю історію. Якщо кільце носиться давно, це триватиме
кілька хвилин.

### 7. Збери дашборд і відкрий

```bash
python3 build_dashboard.py
python3 serve.py
```

Відкрий у браузері `http://127.0.0.1:8910/`.

## Що ти отримаєш

Шість вкладок: **Огляд**, **Щоденно** з усіма показниками й поясненнями,
**Потижнево**, **Цикл** із фазами й температурною кривою, **План на тиждень**
на твоїх власних кореляціях і **Словник** термінів.

Кнопка «↻ Оновити з кільця» прямо в дашборді підтягує свіжі дані.
Будь-яку вкладку можна послухати живим українським голосом — безкоштовно, без ключів.

## Часті запитання

**Мої дані кудись ідуть?**
Ні. Дашборд працює на твоєму комп'ютері, дані лежать у теці `data/` поруч із проєктом.
Назовні йде лише запит до самої Oura по твої ж показники.

**Це медичний висновок?**
Ні. Це інформаційний інструмент із твоїх власних даних. Діагнози ставить лікар.

**Треба платити?**
Ні. Кільце й акаунт Oura у тебе вже є, решта безкоштовна. Озвучка теж.

**Щось пішло не так.**
Якщо ставиш через Claude Code — просто опиши йому проблему своїми словами, він розбереться.
Найчастіша помилка — адреса перенаправлення в застосунку Oura відрізняється
від `http://localhost:8765/callback`.
